# 易道能力岛

仿“英语能力岛”的闯关式学习程序：30 天学完《道德经》81 章和《易经》64 卦。

## 怎么用
双击打开 `dist/易道能力岛.html`（Chrome / Edge 都可以，不需要联网和安装）。学习进度自动保存在这台电脑的浏览器里；换电脑前到“设置”里复制进度码。

## 每天的流程（第 1 天多一步“入门”）
1. **读经**：当天 2–3 章《道德经》原文，可朗读、遮字背诵，附白话、古代案例、近现代案例、今日一用
2. **观象**：当天 2–3 卦，卦象图、卦辞、六爻原文和逐爻白话、大象传、彖传、古今案例
3. **对读**：仿书中“《道德经》第X章与《易经》第Y卦”的写法，竖排书页展示一章一卦的共同道理
4. **闯关**：12 题（名句出处、原文填空、认卦象、上下卦、爻位、案例辨析、温故题），答对 60% 得朱印、解锁下一座岛

另有：经典库（全文检索）、卦象训练营、错题本（自动收录、重练移除）、编号对读（如 4841 = 第48章 × 第41卦）、繁简切换。

## 文件
- `data/texts.js`：原文（《道德经》王弼本、《周易》通行本，据维基文库整理），由 `tools/parse_sources.py` 生成
- `data/ddj_notes*.js`、`data/gua_notes*.js`：讲解与案例；`data/plan.js`：30 天计划与对读
- `src/`：界面与程序；修改后运行 `python3 tools/build.py` 重新生成 `dist/易道能力岛.html`
